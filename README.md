# InstaRec
Records the screen automatically while Instagram is open; saves to Movies/InstaRec when it closes.

## Build
1. Open this folder in Android Studio (Koala or newer), let Gradle sync.
2. Run on your phone (USB debugging) or Build > Build APK.

## First-time setup (in the app)
1. Allow notifications.
2. Enable "InstaRec" in Accessibility settings (on Android 13+ you may first need
   App info > ⋮ > Allow restricted settings).
3. Tap "Start recorder" and approve. On Android 14+/15 choose "Entire screen" if asked.
4. Disable battery optimization.

After every phone restart: tap the "Tap to enable auto-recording" notification and approve once.
Videos are video-only (no audio) in this version.
